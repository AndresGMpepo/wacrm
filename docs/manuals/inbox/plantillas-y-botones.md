## ¿Qué es?

WhatsApp exige usar una "plantilla" aprobada para iniciar una
conversación o para responder después de 24 horas sin respuesta del
cliente. Aquí se crean, se envían a aprobación de Meta, y se usan desde
el Inbox o desde una Difusión.

## ¿Para quién es?

Un administrador crea y envía las plantillas a aprobación. Cualquier
agente puede usar una plantilla ya aprobada para responder o iniciar
una conversación.

## Cómo se usa

1. Ve a **Configuración → Plantillas**.
2. Crea una plantilla: texto del cuerpo, encabezado opcional
   (texto/imagen/video/documento), pie de página opcional, y hasta
   varios botones (respuesta rápida, enlace, teléfono, código de
   cupón).
3. Envíala a revisión de Meta — la aprobación suele tardar minutos a
   horas.
4. Una vez **Aprobada**, ya puedes usarla desde el Inbox (botón
   Plantillas del compositor) o en una Difusión.

## Preguntas frecuentes

**Mis plantillas con botones no muestran los botones al enviarlas por
un número conectado vía proveedor externo.**
Esto está en investigación — no es un límite conocido de WhatsApp
(los botones estáticos no deberían necesitar reenviarse en cada
mensaje). Si te pasa, repórtalo con el ID de un mensaje afectado para
poder confirmarlo con el proveedor.

**¿Por qué no puedo editar una plantilla ya aprobada?**
Meta no permite editar una plantilla aprobada — hay que eliminarla y
crear una nueva con los cambios.
