## ¿Qué es?

El paso de "Audiencia" al crear una difusión — define quién la recibe.

## ¿Para quién es?

Cualquier persona que cree difusiones.

## Cómo se usa

Elige una de estas 4 formas de definir a quién llega:

1. **Todos los contactos** — toda tu base de datos.
2. **Filtrar por etiquetas** — solo contactos con una o varias
   etiquetas seleccionadas.
3. **Campo personalizado** — una regla como "Ciudad es Bogotá" o
   "Talla contiene M".
4. **Subir CSV** — una lista de teléfonos (y nombres opcionales) que no
   necesariamente están ya en tu base — se crean como contactos nuevos
   si no existen.

En cualquiera de las 3 primeras opciones, puedes además **excluir por
etiqueta** — por ejemplo, "todos los que tengan la etiqueta 'Nuevo
Cliente', excepto los que además tengan 'No Molestar'".

El resumen de audiencia muestra el número estimado de destinatarios
antes de enviar.

## Preguntas frecuentes

**¿Por qué el número estimado no coincide exactamente con los
enviados al final?**
El estimado se calcula al momento de armar la difusión; contactos
nuevos, dados de baja o archivados entre ese momento y el envío pueden
cambiar el número final.

**¿Los contactos archivados reciben difusiones?**
No, nunca — un contacto archivado se excluye siempre de cualquier
audiencia.
